# Family Monitor — родительский контроль для Windows

Состоит из трёх частей:
- **server/** — сайт с панелью (FastAPI + SQLite), хостится на Render
- **agent/** — один exe для ПК сына (Windows): сам устанавливается, отправляет сводку и транслирует экран на сайт
- **.github/workflows/build-agent.yml** — автоматическая сборка `agent.exe` на GitHub (своего Windows не нужно)

Что видно на сайте: сколько времени сын был за компьютером, какие программы и игры запускал, какие окна/вкладки браузера были открыты, совпадения со списком «плохих» слов (его можно менять прямо на сайте), и живая трансляция экрана по кнопке «Смотреть экран онлайн» — пока страница открыта, в углу экрана сына видна красная плашка «Родитель видит экран».

Программа **не** читает переписку и не записывает нажатия клавиш. Экран передаётся только пока открыта страница просмотра и нигде не сохраняется. Для браузеров виден только заголовок вкладки, а не полный адрес.

**Удалённое управление** (ставить и настраивать программы на ПК сына, когда вы дома) мы с нуля не писали — цена ошибки в безопасности там высокая. Вместо этого — [RustDesk](https://rustdesk.com) (бесплатный, с открытым кодом): по одному exe на оба ПК, и вы управляете компьютером сына с ПК родителя. Напишите, если нужна пошаговая инструкция.

## 1. Сайт на Render

1. Создайте на GitHub **приватный** репозиторий и загрузите в него всю эту папку (`server/`, `agent/`, `.github/`, этот README).
2. На [render.com](https://render.com) → **New → Blueprint** → выберите этот репозиторий. Render найдёт `server/render.yaml` и предложит создать сервис.
   - Если Blueprint не используете: **New → Web Service**, Root Directory `server`, Build Command `pip install -r requirements.txt`, Start Command `uvicorn main:app --host 0.0.0.0 --port $PORT`.
3. В настройках сервиса (Environment) задайте переменные:
   - `PARENT_PASSWORD` — пароль для входа на сайт
   - `AGENT_KEY` — длинный случайный ключ (например, сгенерируйте на [randomkeygen.com](https://randomkeygen.com)) — **этот же ключ** понадобится для сборки агента
   - `TZ_NAME` = `Europe/Kyiv`
4. После деплоя сайт будет на `https://ваше-имя.onrender.com` — это и есть `server_url` для агента (уже с HTTPS, ничего дополнительно настраивать не нужно).

**Особенности бесплатного плана** (он указан в `render.yaml`):
- **База сбрасывается при каждом перезапуске сервиса.** История отчётов и статистика будут периодически пропадать — рассчитывайте на это как на демо-режим, а не на долгую историю. Если понадобится настоящее хранение — на платном плане Starter (~$7/мес) можно подключить постоянный диск, напишите, если захотите перейти.
- **Сайт засыпает примерно через 15 минут без обращений.** Первое открытие после сна займёт до минуты (сервис «просыпается»), и агент на ПК сына может ненадолго перестать достучаться — это не ошибка, отчёты и трансляция экрана возобновятся сами.
- Чтобы сайт почти не засыпал — бесплатно и без смены плана: зарегистрируйтесь на [cron-job.org](https://cron-job.org) (или похожем бесплатном сервисе) и настройте там пинг вашего адреса `https://ваше-имя.onrender.com/` каждые 10 минут. Это не отменяет сброс базы при деплоях, но держит сайт «живым».

## 2. Сборка agent.exe через GitHub Actions

1. В том же репозитории: **Settings → Secrets and variables → Actions → New repository secret**, добавьте:
   - `SERVER_URL` = адрес вашего сайта на Render (например `https://family-monitor-xxxx.onrender.com`)
   - `AGENT_KEY` = тот же ключ, что задали на Render
2. Вкладка **Actions → Build agent.exe → Run workflow** (можно указать имя устройства, например «ПК сына»). Сборка займёт 1–2 минуты.
3. Откройте завершившийся запуск → в разделе **Artifacts** скачайте `agent.exe`. Адрес сервера и ключ уже зашиты внутрь.

Не выкладывайте собранный `agent.exe` в открытый доступ и держите репозиторий приватным — в сборке содержится ваш ключ.

## 3. Установка на ПК сына

Перенесите `agent.exe` на ПК сына (флешкой, облаком, почтой) и просто запустите его (двойной клик). Он сам:
- скопируется в `%LOCALAPPDATA%\FamilyMonitor`,
- добавится в автозапуск текущего пользователя,
- запустится и покажет окно «Установлено».

Удаление: `agent.exe --uninstall` (можно из уже установленной копии, или скачайте тот же файл и запустите с этим флагом).

## Локальный запуск сервера (для проверки на своём ПК, без Render)

```
cd server
pip install -r requirements.txt
set PARENT_PASSWORD=ваш_пароль_для_сайта
set AGENT_KEY=длинный_случайный_ключ
uvicorn main:app --host 0.0.0.0 --port 8000
```
(в PowerShell: `$env:PARENT_PASSWORD="..."; $env:AGENT_KEY="..."`)

Можно также собрать `agent.exe` локально, без GitHub: на Windows с Python 3.10+ выполните `cd agent` и запустите `build.bat` — он спросит адрес сервера, ключ и имя устройства.

## Важно

Предупредите сына, что программа установлена, и объясните зачем. Так честнее, и это лучше работает, чем тайный контроль.
